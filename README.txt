FEEL AND DISCOVER SIARGAO — WEBSITE PROJECT
Files: index.html (Home), about.html, packages.html, booking.html, contact.html, styles.css, script.js, assets/logo-siargao.png.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create/open your GitHub repository.
2. Upload ALL files and the assets folder. Keep the file structure as-is.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and / (root), then Save.
5. Wait for the Pages URL to appear. Open index.html from that live URL.
6. Replace the placeholder email hello@feelanddiscoversiargao.example in booking.html and contact.html with a real email before using the inquiry form.

IMAGE NOTES
The site uses Wikimedia Commons photographs of Siargao landmarks via Commons Special:FilePath URLs. Check the source page and attribution/license details before redistributing or changing image usage. The logo file is included locally.

IMPORTANT
This is a front-end student project. The booking form opens a pre-filled email draft; it does not store bookings, take payments, or confirm availability. Package prices are estimates and should be verified with real operators.
